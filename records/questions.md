# Open questions

Migrated from `rps-belief-circuits-questions-register-2026-09-19.md` (Q1, Q2, and the reiterate list — Q2 itself is answered in place there and folded into `c-terminology`'s epistemic-parity entry; only Q1 and the terms register are open) and from the reconciled register Part 4.

Live now:

- Which circuit-identity metric, fixed in advance? Three candidates (representational similarity at matched layers / CKA; probe-direction alignment after optimal head permutation; functional equivalence under head transplant), none obviously dominant. Without one, `s-uniqueness` is not a measurement.
- Can a rich-gradient, poor-readout control be constructed? If not, `s-representation-vs-demand` bounds rather than identifies.
- Grounding for the game-theoretic notion of belief — entry point is the betting elicitation of degree of belief, and whether beliefs range over strategies, types, or states of the world.
- **What is `r-multiconsumer`'s training design?** Genuinely new, previously unbudgeted work required by `s-crit-multiconsumer` — none of the source documents specify what the second consumer of the shared belief state should be (a second payoff structure? a second solver query? something else), or the architecture needed to pose multiple decision problems jointly. Not to be spec'd unilaterally; needs Ramsey's decision.
- Which opponent-family set survives the distinguishability gate (phase 2, R27)? Determined by a calculation — expected divergence per round between candidate families, hence rounds-to-separate — that has not been run. Answerable before any phase-2 code is written, but not yet answered.
